# IAA – Asistente para consorcios

TP grupal de Inteligencia Artificial Agéntica (Maestría en Data Mining, UBA) – Grupo 6.

Asistente que responde consultas sobre el reglamento y las actas de un consorcio citando la fuente, responde consultas de expensas por unidad, y deriva a la administración lo que no puede resolver.

## Qué hay en el repo

- `docs/informe.md`: el informe del TP, organizado según lo que pide la consigna.
- `docs/bitacora.md`: notas de cómo fue el desarrollo.
- `datos/`: datos procesados y el set de preguntas para evaluar. Los documentos originales del consorcio no se suben porque tienen datos personales; están en el Drive del grupo.
- `src/`: el código.
